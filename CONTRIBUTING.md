# Contributing to Framework Elite Copilot

¡Gracias por tu interés en contribuir! 🎉

## 🤝 Cómo Contribuir

### Reportar Bugs

Si encuentras un bug, por favor:

1. Busca primero en [Issues](https://github.com/Melampe001/.githum-copilot-instructions.md/issues) para ver si ya fue reportado
2. Si no existe, crea un nuevo issue con:
   - Descripción clara del problema
   - Pasos para reproducirlo
   - Comportamiento esperado vs actual
   - Screenshots si aplica
   - Tu entorno (OS, VS Code version, Copilot version)

### Sugerir Mejoras

¿Tienes una idea para mejorar el framework?

1. Abre un issue con la etiqueta `enhancement`
2. Describe tu idea claramente
3. Explica por qué sería útil
4. Si es posible, sugiere una implementación

### Pull Requests

1. **Fork** el repositorio
2. **Crea una rama** para tu feature:
   ```bash
   git checkout -b feature/nombre-descriptivo
   ```
3. **Haz tus cambios** siguiendo las guías de estilo
4. **Commit** con mensajes claros:
   ```bash
   git commit -m "Add: Nueva funcionalidad X"
   ```
5. **Push** a tu fork:
   ```bash
   git push origin feature/nombre-descriptivo
   ```
6. **Abre un Pull Request** explicando tus cambios

## 📝 Guía de Estilo

### Commits

Usa el formato:

```
Tipo: Descripción corta (máx 50 chars)

Descripción detallada si es necesaria (max 72 chars por línea)
```

Tipos:
- `Add`: Nueva funcionalidad
- `Fix`: Corrección de bug
- `Update`: Actualización de funcionalidad existente
- `Docs`: Cambios en documentación
- `Style`: Formateo, punto y coma faltante, etc.
- `Refactor`: Refactorización de código
- `Test`: Agregar o modificar tests
- `Chore`: Tareas de mantenimiento

### Código

- **Markdown**: Usa formato consistente
- **Comentarios**: Claros y concisos
- **Ejemplos**: Realistas y funcionales

### Documentación

- Escribe en español (idioma principal del proyecto)
- Usa ejemplos claros
- Incluye código funcional
- Agrega screenshots cuando sea útil

## 🧪 Testing

Antes de hacer un PR:

1. Verifica que los archivos de configuración son válidos
2. Prueba los templates con GitHub Copilot
3. Revisa que la documentación sea clara

```

└── nombre-template/
```
